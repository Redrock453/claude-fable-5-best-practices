# 6. Экономика, лимиты, безопасность, приватность

## 6.1 Цены

| Позиция | Значение |
|---|---|
| Input | $10 / 1M токенов |
| Output | $50 / 1M токенов |
| Prompt caching | −90% на кэшированный вход (write ×1.25 / ×2 для 1h TTL) |
| US-only inference | ×1.1 к тарифам |
| Batches API | −50% (стандартная скидка) |
| Для сравнения | Opus 4.8: $5/$25; Sonnet 5: $3/$15 |

Ориентиры сообщества: вход ~×23, выход ~×57 дороже DeepSeek V4 Pro ([Habr](https://habr.com/ru/articles/1046736/)) — то есть Fable 5 не «модель по умолчанию», а инструмент под задачи соответствующей ценности.

### Практики снижения стоимости

1. **Кэшируйте всё стабильное** (system, инструменты, few-shot): порядок рендера `tools → system → messages`, волатильное — после последнего breakpoint. Минимальный кэшируемый префикс Fable 5 — 2048 токенов.
2. **Батчи** для нелатентных задач: −50%.
3. **Effort вниз на рутине** — `medium`/`low` у Fable ≈ `max` прошлых моделей.
4. **Fallback-credit** (`fallback-credit-2026-06-01`) при ручных ретраях после refusal — кэш переоценивается по read-тарифам.
5. **Дешёвые модели для мелочи**: Sonnet 5 / Haiku 4.5 — классификация, извлечение, короткие ответы.

## 6.2 Лимиты подписок

- Fable 5 доступна подписчикам Pro, Max, Team, Enterprise — но **не более 50% ёмкости плана**.
- Сгорает недельный лимит быстрее любой другой модели Claude.
- Летом 2026 доступ по подпискам ограничивался (переход на credits; источники расходятся в дате — 7 или 12 июля); заявлено намерение вернуть в подписки по мере роста ёмкости.
- Rate limits API — свои для Fable-тарифа; при 429 у fallback-модели fallback-попытка не делается (возвращается refusal с `stop_details.recommended_model`).

## 6.3 Классификаторы безопасности

- Цели: offensive cybersecurity, биология/life sciences, извлечение reasoning. Fable 5 **не предназначена** для этих доменов.
- Ложные срабатывания на легитимной смежной работе (security-инструменты, life-science-задачи) — ожидаемы; потому fallback-паттерны обязательны даже для «чистых» воркфлоу.
- Отказ = HTTP 200 + `stop_reason: "refusal"` + `stop_details {category, explanation}`. Категории: `"cyber"`, `"bio"`, `"reasoning_extraction"`, `"frontier_llm"`, `null`.
- До вывода — пусто и не биллится; mid-stream — частичный вывод биллится (отбрасывайте его, не считайте ответом).
- Заявление Cloudflare-доков: доступ к Fable 5 может ограничиваться по директиве правительства США — модель в этот период возвращает ошибки ([Cloudflare](https://developers.cloudflare.com/ai/models/anthropic/claude-fable-5/)). Закладывайте graceful degradation на Opus 4.8.

## 6.4 Приватность и retention

- **Обязательное 30-дневное хранение данных** для исследования джейлбрейков — Fable 5 недоступна под Zero Data Retention. Организация с ZDR/укороченным retention получает `400 invalid_request_error` на каждый запрос — проверяйте конфигурацию организации до отладки payload.
- На Amazon Bedrock требуется opt-in в data sharing (`data_retention: provider_data_share`) — данные покидают security boundary AWS.
- Вывод: **не отправляйте в Fable 5 то, что не может храниться 30 дней** (регуляторика, NDA, персональные данные) — используйте Opus 4.8 (совместим с ZDR).
