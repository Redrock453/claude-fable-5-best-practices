# Экономика и выбор модели: когда Fable 5, а когда нет

Fable 5 — $10/$50 за 1M (×2 к Opus 4.8: $5/$25; Sonnet 5: $3/$15). Это не «модель по умолчанию», а инструмент под задачи соответствующей ценности.

## Правило выбора

- **Fable 5**: задача заняла бы у человека **от двух недель** — многодневные исследования, миграции кодовых баз, end-to-end deliverables, долгие автономные запуски. Отрыв растёт с длиной и сложностью задачи.
- **Opus 4.8**: быстрые правки, ZDR/строгий retention, security/bio-смежные домены (у Fable там классификаторы), рутинные агентные фоны.
- **Sonnet 5 / Haiku 4.5**: классификация, извлечение, короткие ответы, массовые пайплайны.
- Не гоняй Fable 5 на простых воркфлоу «для теста» — на них выгоднее младшие модели, а отрыв Fable не виден.

## Снижение стоимости (обязательный минимум)

1. **Prompt caching** — до −90% входа; порядок `tools → system → messages`, стабильный префикс ≥ 2048 токенов.
2. **Batches API** для нелатентных задач — −50%.
3. **Effort вниз на рутине** — `medium`/`low` у Fable ≈ `max` прошлых моделей.
4. **Fallback-credit** (`fallback-credit-2026-06-01`) при ручных ретраях после refusal.
5. Мелочь — на Sonnet 5 / Haiku 4.5.

## Лимиты и деградация

- Подписки Pro/Max/Team/Enterprise: на Fable — максимум 50% ёмкости плана; недельный лимит сгорает быстрее любой модели.
- При 429 у fallback-модели fallback-попытка не делается (придёт refusal с `stop_details.recommended_model`).
- Доступ может ограничиваться внешними директивами — закладывай graceful degradation на Opus 4.8.

## Приватность — проверять до внедрения

- Обязательное **30-дневное хранение**; ZDR/укороченный retention → 400 на каждый запрос.
- На Bedrock — opt-in в data sharing (`data_retention: provider_data_share`), данные покидают security boundary AWS.
- Регуляторика, NDA, персональные данные → Opus 4.8 (совместим с ZDR), не Fable 5.

## Чек-лист внедрения

- [ ] Ценность задачи оправдывает $10/$50 (правило «двух недель»)?
- [ ] Retention организации ≥ 30 дней?
- [ ] `stop_reason: "refusal"` обрабатывается; fallbacks включены?
- [ ] Prompt caching настроен; префикс ≥ 2048 токенов?
- [ ] Стриминг + таймауты под минуты-долгие запросы?
- [ ] Дашборды cost/latency перебазированы на тарифы Fable?
- [ ] Рутина уведена на Sonnet 5 / Opus 4.8?
